# Bryan M. Sabejon — Professional Portfolio

A responsive, static portfolio introducing Bryan's work across web design, full-stack engineering, infrastructure, and applied AI.

## Pages

- `index.html` — Professional introduction, core expertise, current focus areas, and GitHub link.
- `about-us.html` — Background, approach, and technical toolkit.

## Built with

- HTML and CSS
- A shared stylesheet at `css/portfolio.css`
- The existing portrait at `images/bryprofile.jpg`

There is no build step or package installation required. The Google Fonts import is optional; the stylesheet includes system-font fallbacks.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server.

## Publish with GitHub Pages

The site is a static GitHub Pages-ready site. In the repository's **Settings → Pages**, select the `master` branch and the repository root as the publishing source. GitHub Pages will publish the site from the selected branch.

## Customize

- Update the profile content and navigation in `index.html` and `about-us.html`.
- Adjust colors, typography, and responsive styling in `css/portfolio.css`.
- Replace `images/bryprofile.jpg` to use a different portrait.
- Update the GitHub profile links in the HTML if the portfolio moves to another account.
